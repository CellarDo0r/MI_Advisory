# Business Setup OS Dashboard

This is the single entrypoint for business setup tracking.

## Quick Status
- Current phase: Setup and planning.
- Primary owner: Founder.
- Today: Update daily log, decisions, and action priorities.

## Daily Workflow (10-15 min)
1. Update [Daily Log](./daily/2026-02-24.md).
2. Record decisions in [Decision Log](./registers/decision_log.md).
3. Set tomorrow's Top 3 in [Action Register](./registers/action_register.md).

## Rules
- One source of truth: update registers, do not duplicate trackers elsewhere.
- Decision first: if direction changes, log the decision immediately.
- Top 3 rule: define only 3 high-priority outcomes per day/week.
- Red flag trigger: any High likelihood + High impact risk is escalated in weekly review.
