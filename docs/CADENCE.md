# Operating Cadence

## Daily Closeout (10-15 min)
1. Add a new entry in `docs/daily/YYYY-MM-DD.md`.
2. Add or update decisions in `docs/registers/decision_log.md`.
3. Update `docs/registers/action_register.md` and set next-day Top 3 priorities.

## Weekly Review (30-45 min)
1. Review risks in `risk_register.md`.
2. Review compliance status in `compliance_tracker.md`.
3. Review cashflow/costs in `finance_tracker.md`.
4. Confirm top 3 priorities for next week.
5. Archive completed actions from `action_register.md` into `docs/registers/archive_completed_actions.md`.

## Monthly Reset (60 min)
1. Re-check assumptions in `assumptions_log.md`.
2. Reconfirm timelines and milestones.
3. Identify new dependencies, resourcing gaps, and external blockers.
